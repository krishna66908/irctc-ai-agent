# IRCTC AI Agent

Personal browser automation assistant for IRCTC.

## Status

🚧 Project under development.

## Tech Stack

- Node.js
- Playwright

## Security

Credentials and other secrets are stored locally and are never committed to Git.

## Task 1 Demo

Run the first browser milestone with:

```bash
npm install
npm run demo
```

This opens the IRCTC train search page, detects the language popup semantically, clicks English, and keeps the browser open for visual verification.
